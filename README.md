# SFO Flight Operations Analysis | March 2020

## Project Overview

This project presents an interactive Tableau dashboard analyzing flight operations at San Francisco International Airport (SFO) during March 2020.

The analysis explores flight activity, busiest destinations, daily departure patterns, and flight-route distances through interactive visualizations.

The dashboard was developed as an academic Tableau case study and enhanced for professional portfolio presentation.

## Tools & Technologies

- **Tableau Public** – Data visualization and interactive dashboard development
- **Calculated Fields** – Flight route and distance analysis
- **Sets** – Identifying top-performing destinations and flight routes
- **Parameters** – Dynamic Top N route analysis
- **Geographic Mapping** – Visualizing flight routes from SFO
- **Dashboard Actions** – Interactive filtering and exploration

## Dataset Overview

The dataset contains **88,532 flight records** for March 2020.

### Key Dashboard Metrics

| Metric | Value |
|---|---:|
| Total Flight Records | 88,532 |
| Flights Departing from SFO | 42,959 |
| Unique Destinations from SFO | 135 |
| Average Flight Distance from SFO | 2,635 km |

## Dashboard Features

### 1. Flight Operations KPIs
Four summary indicators provide an overview of total flight activity, SFO departures, unique destinations, and average flight distance.

### 2. Top 5 Busiest Cities vs. Other Cities
Uses Tableau Sets to distinguish the five busiest destinations from other cities while retaining the complete destination distribution.

### 3. Top 10 Busiest Days
Highlights the ten busiest days for flights departing from SFO during March 2020.

### 4. Daily Flight Departure Trends
A time-series visualization showing changes in SFO departures throughout the month.

### 5. Geographic Flight Route Analysis
An interactive geographic visualization displaying flight routes originating from SFO, with destination and distance information available through tooltips.

### 6. Dynamic Top N Longest Flight Routes
An additional worksheet uses a Tableau parameter and set to explore the longest flight routes dynamically.

## Key Observations

- SFO recorded **42,959 departures** across **135 unique destinations** in the dataset.
- Average flight distance from SFO was approximately **2,635 km**.
- Flight departures declined toward the end of March 2020.
- Flight activity varied across destinations, with the busiest cities accounting for a prominent share of flights.

These findings describe patterns in the dataset and do not independently establish the causes of changes in flight activity.
